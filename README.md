# Bar Guild — Telegram Mini App

Текущий интерфейс уже готов к запуску внутри Telegram:

- подключён официальный Telegram Web Apps SDK;
- приложение разворачивается на весь экран и учитывает безопасные зоны телефона;
- цвет шапки и фона согласован с чёрной темой Bar Guild;
- имя и первая буква аватара берутся из профиля Telegram только для отображения;
- системная кнопка «назад» Telegram возвращает пользователя на главную;
- лёгкая тактильная отдача добавлена к отметкам чек-листа, навигации и наградам.

## Публикация

Мини-приложение — это статический сайт. Его нужно разместить на хостинге с HTTPS; после этого у него появится адрес вида `https://bar-guild.example`.

Файлы для публикации — вся эта папка, включая `index.html` и каталог `assets`.

## Подключение к боту

1. В Telegram откройте `@BotFather` и создайте бота через `/newbot`.
2. В настройках бота выберите **Bot Settings → Configure Mini App → Enable Mini App**.
3. Укажите HTTPS-адрес опубликованного приложения.
4. Задайте название, иконку и тёмные цвета загрузочного экрана.
5. Нажмите кнопку **Open App** в профиле бота и проверьте запуск на телефоне.

Токен бота никогда не нужно добавлять в `index.html` и не стоит пересылать в чат.

## Что нужно для боевой версии

Сейчас это интерактивный интерфейс без базы данных. Следующим этапом нужен защищённый сервер, который:

- проверяет Telegram `initData`;
- связывает Telegram ID с профилем сотрудника и конкретным заведением;
- хранит миссии, чек-листы, опыт, печати и выдачу наград;
- даёт бар-менеджеру доступ только к его заведению.

До подключения сервера данные на экране остаются демонстрационными и сбрасываются при обновлении страницы.
